## 100 Days of Machine Learning

A structured repository documenting my journey of learning Machine Learning step by step following the CampusX 100 Days of Machine Learning
roadmap. This repository contains Jupyter notebooks, datasets, experiments, visualizations, and implementations of core Machine Learning concepts ranging from data preprocessing to ensemble learning.

## Topics Covered

- Data Analysis & Visualization
- Feature Engineering
- Data Preprocessing
- Regression Algorithms
- Classification Algorithms
- Ensemble Learning
- Dimensionality Reduction
- Model Evaluation
- Hyperparameter Tuning
- Pipelines & Transformers
- Clustering

## Tech Stack

- Python

- Jupyter Notebook
